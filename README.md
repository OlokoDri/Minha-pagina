## 📖 Sobre o projeto

A página inicial apresenta uma breve apresentação pessoal e disponibiliza acesso às minhas principais redes sociais.

Durante o desenvolvimento, também foram criadas páginas para praticar diferentes recursos do HTML e CSS, incluindo:

* 📷 Imagens responsivas utilizando a tag `<picture>`;
* 🎵 Reprodução de áudio com HTML5;
* 🎥 Incorporação de vídeos do YouTube;
* 🎨 Testes de cores e gradientes com CSS;
* 🔗 Navegação entre páginas utilizando links internos.

Este projeto faz parte da minha jornada de aprendizado em Desenvolvimento Web e da construção do meu portfólio como futuro Desenvolvedor Full Stack.

## 💻 Como executar

Clone este repositório:

```bash
git clone https://github.com/OlokoDri/Minha-pagina.git
```

Acesse a pasta do projeto:

```bash
cd Minha-pagina
```

Abra o arquivo **index.html** em seu navegador ou utilize a extensão **Live Server** no Visual Studio Code.
