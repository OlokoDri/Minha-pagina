# Minha pagina

Projeto de pagina pessoal criado com HTML e CSS para praticar estrutura de paginas, links, imagens responsivas, audio e videos.

## Sobre o projeto

A pagina inicial apresenta uma pequena introducao pessoal e links para redes sociais, como GitHub, Instagram, Gmail e LinkedIn.

O projeto tambem possui paginas de teste para:

- Imagens responsivas com a tag `<picture>`;
- Reproducao de audio com HTML5;
- Videos incorporados do YouTube;
- Testes de cores e gradientes em CSS.

## Tecnologias usadas

- HTML5
- CSS3

## Como abrir

Baixe ou clone o repositorio e abra o arquivo `index.html` no navegador.

```bash
git clone https://github.com/OlokoDri/Minha-pagina.git
cd Minha-pagina
```

Depois, abra `index.html`.
